## Wrapping instructions

- Use chapter-specific labels instead of ordinary birthday tags.
- Keep all card packs inside a single lightweight “Booster Satchel” carried by an adult after they are earned. Luca sees each pack before it is placed in the satchel.
- Place an icon on each package matching the app chapter icon.
- Number only the four water capsules. Do not number ordinary rewards.
- Place the actual entry-code digits only on four physical fragment cards. Do not photograph or upload them.
- Make the Champion Chest visually largest.
- Make Mew physically separate and hidden before the game begins.
