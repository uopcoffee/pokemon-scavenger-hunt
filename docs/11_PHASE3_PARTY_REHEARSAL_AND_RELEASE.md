### Safe shortcut points

1. During the 9:52 travel window, skip all optional phone warmups and use the
   time for towels, costumes, and prop handoff. Do not move the 10:15 Oak start.
2. At the Oak return, ask one callback question, immediately award League
   Authorization, and use the skimmer/tub fallback if the pool setup is slow.
3. On Victory Road, use one pass per station, a Legendary Assist after the
   first Rayquaza attempt, and the closest Champion target.

The app keeps Auntie Ariel's Victory Road cue open through Rayquaza. Do not
turn the phone back to Luca or open a second private cue between those connected
activities.

### Emergency compressed route

Use this only when the event is 20–30 minutes behind. Preserve every required
story beat:

- Skip every optional digital warmup.
- Run Fairy Garden with the eight lights already visible and let Nina point directly to each one. An adult still forms the arrow.
- Use the pool skimmer or a dry tub; retrieve all four Oak capsules in one pass.
- Nurse Joy demonstrates the first match; Luca completes one match and carries
  the medicine ball directly back.
- Team Rocket uses one close basket plus a theatrical Final Poké Shot.
- The adult escorts Luca directly to the prepared Ranger cache after the
  physical fragments are read.
- Oak asks one callback question.
- Victory Road becomes a single lap; Rayquaza gets an immediate Legendary
  Assist; Champion keeps all three spoken rounds but uses one easy toss.
- Keep the full fake-credit pause, Mew trail, Mew reveal, and celebration.

This compressed route saves about 24 minutes without removing the Oak pool
mission, Team Rocket, Ranger Vault, Champion, or Mew.

## Live participant scripts

Adults may paraphrase. Pause for Luca's reactions; the lines themselves are
brief enough to reach physical play in about 15–45 seconds.

### Auntie Ariel — League Recruiter

> Trainer Luca! A new region has appeared, and the Pokémon League chose you to
> investigate. Promise to protect Pokémon, help your friends, play fairly, and
> never give up. Then show me how an official Trainer protects one special
> card!

### Auntie Ariel — Victory Road Referee

> Welcome to Victory Road! Clear the Tall Grass, cross the forest line, hit the
> target, and recover the Energy Tokens. I will judge every move with complete
> League fairness—and possibly one very slow Slowpoke penalty. Ready, Trainer?

### Nina — Fairy Gym Leader

Nina may point, pause, or use only one line at a time. Ariel or Polly gives the
longer setup.

> Luca! Lights! I can’t reach! Tree! There! Up high! Table! You did it!

Ariel or the supporting adult explains:

> Eight Fairy lights are glowing in the garden. Nina knows where they are.
> Follow her clues and bring every light to the Fairy Table.

After the eighth light reaches the table:

> Luca, step back. The lights made an arrow. They know where to send you next.

### Bruce — Professor Oak, first visit

> Shhh... the preserve is unusually active. You must be Trainer Luca. Four
> research capsules are waiting, and one carries strange Sky energy. Retrieve
> them safely with Monica, identify the unstable symbol, and bring everything
> to my research tray.

### Monica — Professor Monica, Water Research Professor

> Professor, the readings are rising! Trainer Luca, use this symbol diagram to
> find all four samples. I have the skimmer and towel ready. No running, no
> deep diving, and we can do the entire mission from the deck.

### Bruce and Monica — Oak return

> You brought back the Sky Fragment and the Rangers' file—excellent. Monica,
> open the file. Trainer Luca, tell us one thing you learned today. Any answer
> counts. Your research now qualifies you for the Pokémon League.

### Polly — Nurse Joy

> Trainer Luca, I am glad you are here. Pikachu, Charmander, and Eevee need the
> right care. Match each patient with a treatment, then carry the medicine
> Poké Ball back to me. You may ask for a Nurse Joy hint at any time.

### Mike — Team Rocket Boss

> So you are Professor Oak's new Trainer! This Ranger Dispatch belongs to Team
> Rocket now. Break my basketball defense, earn your points, and attempt the
> Final Poké Shot. My defense is scientifically unbeatable—unless you get
> closer, which would be extremely unfair to me.

### Patrick — Creekside Champion

> Trainer Luca, I watched your whole journey. A Champion needs knowledge,
> skill, and heart. Choose a helpful type, make one comfortable target toss,
> and name someone or a Pokémon who helped you today. Show me all three.

Concession:

> The match is over. Luca, you are the new Champion of the Creekside Region.

## Real-world challenge cards

Parent Mode provides the skip/override path for every physical challenge:
five taps in the top-right corner, then **Override / advance**, or jump directly
to the appropriate challenge.

### Fairy Garden Rescue

- Primary setup: eight glowing flameless battery tea lights hidden in safe backyard locations; Nina knows all eight; a designated adult quietly forms an arrow on the Fairy Table.
- Success: all eight lights reach the table and the arrow is revealed. Nina and adults may point immediately.
- Easier fallback: place every remaining light in full view and let Nina point directly to each one.
- No-prop fallback: use eight paper Fairy symbols and form the same arrow.
- Duration: 4–6 minutes.
- Performer: Ariel runs the scene and prompts Nina only if Nina wants to join.
- Phone Captain: Patrick opens the cue and completes Mission Complete.
- Props: eight battery tea lights, Fairy Table, optional costume piece.
- Safety: use flameless lights only. Every hiding place must be reachable from the ground. No tree, fence, furniture, or ladder climbing and no side-yard access.

### Professor Oak pool research mission

- Primary setup: four double-sealed, clearly marked floating/shallow capsules,
  symbol diagram, dry tray, towel, and dedicated water watcher.
- Success: safely recover four objects and place the Sky Fragment in the tray.
- Easier fallback: retrieve everything with the skimmer from the deck.
- No-prop fallback: use four marked tennis balls in a dry tub or on a towel.
- Duration: 12–15 minutes plus reward reveal.
- Water Safety Adult: one dedicated adult watches Luca continuously and never
  operates the phone.
- Phone Captain: Polly or Auntie Ariel opens the cue and completes Mission
  Complete; Monica manages props.
- Props: four capsules, diagram, skimmer, towel, tray, Sky Fragment.
- Safety: no running, no deep diving, no unsupervised water entry, and no
  valuable item without double containment.

### Nurse Joy challenge

- Primary setup: three patient cards, three treatment cards, and a medicine
  Poké Ball delivery path.
- Success: complete all matches with unlimited hints and carry the medicine.
- Easier fallback: remove one wrong option or demonstrate the first match.
- No-prop fallback: Nurse Joy speaks two choices for each patient; Luca points.
- Duration: 5–7 minutes.
- Performer: Polly runs the scene.
- Phone Captain: Patrick opens the cue and completes Mission Complete.
- Props: six cards, soft ball, two path markers.
- Safety: keep the carry path short, dry, and free of trip hazards.

### Team Rocket basketball mission

- Primary setup: adjustable hoop, close markers, ball, large fallback target.
- Success: cumulative points; after misses, move closer; Mike always loses.
- Easier fallback: closest marker, lower hoop, or count backboard/target hits.
- No-prop fallback: three soft underhand passes to Mike break the defense.
- Duration: 5–7 minutes.
- Performer: Mike performs; Ariel can replace him.
- Phone Captain: Patrick or Auntie Ariel opens the cue and completes Mission
  Complete.
- Props: hoop, soft or child-sized ball, markers, Ranger Dispatch.
- Safety: clear the shooting lane and keep spectators behind Luca.

### Secret Ranger Vault

- Primary setup: combination box set to `0151`, adult escort, and cache staged
  in Hannah and Noa's yard.
- Success: adult-accompanied opening and safe recovery of cache/research file.
- Easier fallback: the adult helps set the combination or opens the box.
- No-lock fallback: adult opens the prepared box and gives the Ranger
  transmission verbally.
- Duration: 5–7 minutes.
- Performer and Phone Captain: the designated Adult Escort remains beside Luca
  and operates the protected controls.
- Props: combination box, cache, and sealed file.
- Safety: keep the box in the prepared yard location and have the escort stay beside Luca.

### Professor Oak return checkpoint

- Primary setup: Sky Fragment, sealed file, League Authorization, reward file.
- Success: present both items and answer any one friendly callback.
- Easier fallback: offer two choices or accept a prompted answer.
- No-prop fallback: Oak announces the scan result and awards authorization.
- Duration: 3–6 minutes.
- Performers: Bruce and Monica lead as equal Partner Professors; Monica opens
  the file and manages rewards.
- Phone Captain: Patrick opens the cue and completes Mission Complete.
- Props: quest items, authorization card, reward package.
- Safety: keep the checkpoint dry and away from the pool edge.

### Victory Road

- Primary setup: four stations—markers, balance line, bucket/target, tokens.
- Success: one supported pass through each; accuracy never hard-fails.
- Easier fallback: shorten the path, widen targets, reveal tokens.
- No-prop fallback: weave around adults, follow a visible floor line, point to
  three targets, and retrieve three named objects.
- Duration: 5–7 minutes.
- Performer: Ariel referees.
- Phone Captain: Patrick opens the cue and completes Mission Complete.
- Props: cones/streamers, line, soft balls, target, three tokens.
- Safety: no elevated balance beam, hard balls, blind running, or crowded lane.

### Mega Rayquaza encounter

- Primary setup: hanging soft target and soft Poké Ball.
- Success: one hit or a Legendary Assist after two minutes.
- Easier fallback: move closer or switch to ring toss.
- No-prop fallback: assemble or point to three Sky symbols.
- Duration: 2–3 minutes.
- Performer: Ariel controls the Assist.
- Phone Captain: Patrick opens the cue and completes Mission Complete.
- Props: target, soft ball; optional rings/symbols.
- Safety: secure hanging props and keep throws away from faces and windows.

### Champion battle

- Primary setup: three type-choice cards and one easy target toss.
- Success: every sincere answer counts; target moves closer after a miss.
- Easier fallback: Patrick gives two choices and uses the closest marker.
- No-prop fallback: all three rounds are spoken; the skill round is a high-five.
- Duration: 3–4 minutes.
- Performer: Patrick performs and concedes.
- Phone Captain: Auntie Ariel opens the cue and completes Mission Complete.
- Props: type cards, soft target game, Champion Chest.
- Safety: use only a soft object and a clear throwing lane.

### Mew epilogue

- Primary setup: three pink markers leading to a separate Mew reveal box.
- Success: follow the prepared route and discover Mew; warm/cold hints allowed.
- Easier fallback: move markers into open view or transmit the next clue.
- No-prop fallback: Professor Oak gives three spoken location clues, ending at
  the adult-held Mew reward.
- Duration: 5–6 minutes.
- Performer: Patrick or the Lead Adult guides the trail.
- Phone Captain: Polly or Auntie Ariel opens the cue and completes Mission
  Complete while Patrick guides Luca.
- Props: three markers, reveal box, Mew figure.
- Safety: backyard tree, bush, and patio route only; no climbing or street edge.

### Popsicle and booster celebration

- Primary setup: seated/clear table, cooler, Booster Satchel, sleeves, waste bag.
- Success: everyone gathers; Luca opens saved packs with adult help.
- Easier fallback: open only one pack and take the rest inside.
- No-prop fallback: group photo and Champion toast; treats/packs can follow.
- Duration: 20–30 minutes.
- Adult: Patrick controls the Satchel; another adult handles food/cooler.
- Props: treats, Satchel, sleeves, table, waste bag.
- Safety: check food needs, keep small card wrappers away from young children,
  and keep wet treats away from cards.

## Party-day recovery

- Page reloads: wait for the saved scene to return. If the map appears, tap the
  active chapter; it resumes the saved scene.
- Phone locks: unlock it and return to the same browser tab. Progress is saved
  after every state transition.
- Progress looks wrong: open Parent Mode, note the current chapter/scene, use
  **Go back one scene** or **Jump to chapter**. If needed, paste the latest
  exported progress and choose **Restore validated progress**.
- Participant unavailable: use the named replacement/fallback above. The app
  records mission completion, not performer identity.
- Challenge must be skipped: open Parent Mode on the physical challenge and use
  **Override / advance**. Briefly narrate the story result and continue to the
  reward; never withhold the reward.
- Saving warning appears: do not close the page. Export progress from Parent
  Mode and keep the JSON in a private note until the phone permits storage.
- Full ending completed: the completed map remains available. A replay requires
  Parent Mode → **Reset game progress** → the second confirmation.

Do not run these commands until deployment is explicitly approved.

### Push the candidate branch

```sh
git checkout feature/creekside-v2
git status --short --branch
node tests/phase1-state.test.js
node tests/phase2-content.test.js
node tests/phase3-release.test.js
git push origin feature/creekside-v2
```

### Create the V2 candidate backup tag

Replace `v2.0-rc1` only if that tag already exists.

```sh
git checkout feature/creekside-v2
git tag -a v2.0-rc1 -m "Creekside V2 final candidate"
git push origin v2.0-rc1
```

### Merge safely to main and deploy

Record the printed pre-deployment SHA somewhere private; it is the exact
rollback target.

```sh
git checkout main
git pull --ff-only origin main
git rev-parse HEAD
git merge --no-ff feature/creekside-v2 -m "Release Creekside V2"
node tests/phase1-state.test.js
node tests/phase2-content.test.js
node tests/phase3-release.test.js
git push origin main
```

### Verify GitHub Pages

Wait for the Pages deployment to finish, then:

```sh
curl -fsSIL https://uopcoffee.github.io/pokemon-scavenger-hunt/
curl -fsSL https://uopcoffee.github.io/pokemon-scavenger-hunt/ | grep -F "creekside-content.js"
```

Open the URL in a private tab and verify onboarding, one chapter scene, refresh,
and Parent Mode. A `200` response alone does not prove the newest commit is live;
compare the Pages deployment SHA with the pushed `main` SHA in GitHub.

### Roll back to `v1.0-original`

This creates a new rollback commit and preserves history:

```sh
git checkout main
git pull --ff-only origin main
git branch backup/pre-v1-rollback
git restore --source=v1.0-original --staged --worktree .
git commit -m "Rollback: restore v1.0-original"
git push origin main
```

### Roll back to the pre-deployment main commit

Replace `<PRE_DEPLOY_MAIN_SHA>` with the SHA recorded before the V2 merge:

```sh
git checkout main
git pull --ff-only origin main
git branch backup/pre-deployment-rollback
git restore --source=<PRE_DEPLOY_MAIN_SHA> --staged --worktree .
git commit -m "Rollback: restore pre-deployment main"
git push origin main
```

After either rollback, wait for Pages to rebuild and repeat the HTTP and private
tab checks. Do not force-push `main`.
